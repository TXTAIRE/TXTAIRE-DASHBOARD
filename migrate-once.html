TxTAIRE — one-time data migration

Inserts the starting employee roster, recruitment pipeline demo, probation tracking, and a month of neutral "present" attendance into your Supabase project. Run this once against a fresh project (empty tables), then delete this file — it embeds real employee names and pay rates in plain text. Requires js/supabase-config.js to already have your real Project URL and anon key filled in.
